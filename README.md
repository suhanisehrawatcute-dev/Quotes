# Tidbits of Wisdom

Generates some wise ideas from a list.

## Description

Tidbits of Wisdom is a web application, built using HTML, CSS and JavaScript, designed to uplift you without requiring any  distracting elements. It serves as a blueprint for developers looking to build basic website-building skills and positioning in CSS. It also contains generator code, which is helpful for many developers.

## Getting Started

### Dependencies

* You only need a modern web browser to run this web application.

### Installing

1. Clone the repository
2. Navigate into the project folder:
   ```bash
   cd quote-generator
   ```
3. Open `index.html` directly in your browser or run it via a local development server (like Live Server in VS Code).
