# Tidbits of Wisdom
The home screen has a funny quote. And when you press New Quote, Tidbits of Wisdom displays a randomly selected quote from a selection of 11 (all written by yours truly).
It can be used by opening the demo link and clicking "New Quote"
The demo link is this "https://suhanisehrawatcute-dev.github.io/Quotes/"
